# I002 UI 与功能优化迭代

**迭代编号：** I002
**目录标识：** I002-ui-function-optimization
**状态：** 实施中
**计划开始：** 2026-08-18
**计划封板：** 待定

## 1. 迭代目标

在 I001 已交付能力之上，降低控制台的学习和操作成本，补齐关键工作流的状态反馈与恢复路径，让用户可以更快地发现异常、定位资源并完成诊断、巡检和受控操作。所有改进保持现有 Scope、RBAC、审计和受控执行边界不变。

## 2. 迭代范围

本迭代聚焦 Svelte 控制台及其直接依赖的 API 交互体验：

- 统一导航、页面层级、加载/空数据/错误状态和通知反馈；
- 优化概览、组织资源、发现导入、诊断、巡检和操作审批的高频路径；
- 提升窄屏布局、键盘操作、焦点可见性和表单可读性；
- 为关键交互补充组件测试和 Playwright 验收覆盖。

不在本迭代范围内：重新设计后端领域模型和权限模型；引入新的外部身份协议；将 Markdown Skill 编辑与细粒度 Tool Catalog（OI-006）提前并入本迭代；改变任何受控操作的审批或执行边界。
