## 状态约定

- `提议`：正在评估，尚不能作为实现依据。
- `已接受`：当前有效决策。
- `已弃用`：不再建议用于新实现，但历史系统可能仍依赖。
- `已替代`：由另一份 ADR 取代，并保留链接关系。

新增 ADR 只能记录会长期约束多个模块、构建发布或运维边界的决定。局部重构、命名调整和可由代码直接看出的实现细节不创建 ADR。
