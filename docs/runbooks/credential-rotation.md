# 凭据与密钥轮换

**适用范围**：PostgreSQL、Redis、Webhook/LLM Token 和 `OPSK_CREDENTIAL_KEY`。

1. 创建新凭据，保留旧凭据且不立即撤销。
2. 在预发布环境验证连接、最小权限和审计记录。
3. 更新 Secret 后滚动发布，确认所有 Pod 都使用新 Secret revision。
4. 观察一个完整业务周期，再撤销旧凭据。

`OPSK_CREDENTIAL_KEY` 会加密资源凭据，不能仅替换环境变量。当前版本尚无在线双密钥重加密命令；轮换前必须导出凭据密文备份，在维护窗口通过受审批的离线迁移完成全量重加密。无该工具时不得直接更换密钥，应将其视为已知限制并安排专项任务。
