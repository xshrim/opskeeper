## 3. 已验证边界

1. 健康评分只由确定性规则及权重计算；LLM 只解释异常，不能改变分数。
2. LLM 不可用时，确定性巡检仍完成并以 `llm_status=degraded` 明示降级。
3. 调度窗口和投递均有幂等约束；Webhook 使用持久投递记录、签名、限流和退避重试。
4. T13 不包含邮件/短信通知、容量预测和自动变更；Webhook 仅传递通知，不执行处置。
