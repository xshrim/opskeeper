## 1. 迭代目标

从空仓库建立可本地启动、可测试、可部署的 OpsKeeper 首个完整版本，覆盖组织与权限、统一资源目录、Kubernetes 发现、外部 Connector、LLM 与 Skill、AI 诊断、自动巡检、受控操作以及生产化基线。

## 2. 迭代范围

- 建立 Go/Svelte 工程、数据库迁移、本地开发环境和质量门禁。
- 实现平台、团队、项目三级 Scope，以及身份、会话、RBAC 和安全审计。
- 实现资源、凭据、关系、拓扑、Kubernetes 发现与 Connector。
- 实现 LLM Provider、Skill、AI 诊断、内置诊断和自动巡检。
- 实现 MCP、操作审批、隔离执行、可观测、安全加固和 Helm 部署。
- 形成开发、管理、使用、交付和生产恢复文档。
